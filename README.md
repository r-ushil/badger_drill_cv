# Badger - Computer Vision Microservice

## Other Components

Frontend: https://github.com/r-ushil/badger_frontend.git
API Server: https://github.com/r-ushil/badger_api_server.git

### Usage

1. Clone the repo
 ```sh
 git clone https://github.com/r-ushil/badger_drill_cv.git
 ```
2. Download Python 3.10
3. Download pip3
4. Install libraries using the following command
 ```sh
 pip3 install -r requirements.txt
 ```
